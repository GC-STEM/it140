# IT 140 Main Course Repository | Script Log Files

- **Course**: IT 140 - *Introduction to Scripting*
- **Module Name**: Main Course Repository
- **Activity Name**: Script Log Files
- **Activity Description**: This folder will contain log files generated by the course automation scripts on the user's system after they clone this repository and run the scripts. These log files will provide information about the execution of the scripts, including any errors or warnings encountered during the process. The logs will be useful for troubleshooting and understanding the behavior of the scripts in different environments.
