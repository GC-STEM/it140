## Workflow for running scripts

### Codio Administrators

1. Run the `master/setup_cvd.sh` script to set up the Codio environment for the course.
2. Publish the course master CVD.

### IT 140 Students

1. Copy, paste, and run the bootstrap commands in `bootstrap_cvd.sh`. These commands will download the remaining automation scripts.
2. Run `update_cvd.sh` to update the CVD to the latest version.
3. Run `configure_cvd.sh` to configure the CVD for the course.
4. Run `verify_cvd.sh` to verify that the CVD is configured correctly.
